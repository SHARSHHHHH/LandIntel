# Land Intelligence Platform

```
npm install
npm run dev
```

Open http://localhost:3000 — it now lands on `/login`, the single entry point for
all three portals (Government/Policy, Researcher/Academic, Public/Citizen).
Use one of the three "Continue as ... demo user" buttons to jump straight into
a portal with its existing seeded demo account, or sign up for your own
Public/Citizen or Researcher/Academic account.
